# Parcelly 📦

**כל החבילות שלך, במקום אחד.**

Parcelly היא אפליקציית ווב לנייד (RTL, עברית) שמרכזת את כל החבילות שלך ממקורות שונים —
AliExpress, SHEIN, Temu, Amazon, iHerb, ZARA ועוד — למסך אחד מסודר: סטטוס, מה יש בחבילה,
מתי היא מגיעה, לאן, ומה אפשר לעשות עם זה.

---

## מה יש באפליקציה

| מסך | מה הוא עושה |
| --- | --- |
| **החבילות שלי** (`/`) | כרטיס לכל חבילה עם לוגו החנות, סטטוס, תאריך הגעה משוער, מספר מעקב ופס התקדמות. סינון לפי הכל / בדרך / מגיע היום / דורש פעולה |
| **פרטי חבילה** (`/package/:id`) | ציר זמן מלא, תוכן החבילה ומחירים, פרטי מסירה, שעות איסוף, היסטוריית מעקב, יצירת קשר עם המוכר |
| **הדבקת SMS** (`/paste`) | מדביקים הודעת שליח — האפליקציה מזהה מספר מעקב, חנות, חברת שילוח, סטטוס, תאריך וקישור לשינוי נקודת איסוף |
| **הוספת חבילה** (`/add`) | הוספה ידנית של מספר מעקב, עם זיהוי אוטומטי של חברת השילוח |
| **הודעות** (`/notifications`) | פיד עדכונים: נשלחה, הגיעה לישראל, דורשת פעולה, נמסרה |
| **דורש פעולה** (`/action-required`) | כל החבילות שממתינות לך: בחירת נקודת איסוף, מכס, תשלום, מסירה חוזרת |
| **היסטוריית הזמנות** (`/history`) | חבילות שנמסרו, מקובצות לפי חודש, עם חיפוש וסכום הזמנות |
| **כתובות שלי** (`/addresses`) | ניהול כתובות משלוח ונקודות איסוף קרובות עם שעות פתיחה |
| **חיבור מקורות** (`/sources`) | חיבור Gmail / Outlook / SMS / חשבונות חנויות |
| **הגדרות** (`/settings`) | העדפות התראות, ניהול נתונים |
| **עזרה ותמיכה** (`/help`) | שאלות נפוצות |
| **מסך פתיחה** (`/welcome`) | דף הנחיתה שמציג מה האפליקציה עושה |

### פעולות שאפשר לבצע על חבילה

- שינוי מקום המסירה — מעבר בין משלוח עד הבית לנקודת איסוף, ובחירת נקודה אחרת
- צפייה בשעות האיסוף של הנקודה, כולל "פתוח עד..." / "נפתח מחר ב..."
- מעבר לקישור של חברת השילוח לשינוי כתובת
- יצירת קשר עם המוכר: צ׳אט, מייל, טלפון, מעבר לעמוד ההזמנה
- העתקת מספר מעקב, מעקב באתר חברת השילוח
- סימון כנמסרה, העברה להיסטוריה, מחיקה

## זיהוי הודעות SMS

הליבה של `src/lib/parse.ts` — כל הזיהוי רץ בדפדפן, הטקסט לא נשלח לשום מקום:

- **מספר מעקב** — לפי תווית ("מספר מעקב:", "tracking number"), לפי תבניות של חברות שילוח
  (S10 של דואר ישראל ו‑China Post, Cainiao, UPS, DHL, FedEx, Amazon Logistics, HFD, BOXIT),
  ואחרת לפי תבנית כללית. מספרי טלפון לא נתפסים בטעות.
- **חנות** — לפי מילות מפתח בעברית ובאנגלית
- **סטטוס** — נשלחה / הגיעה לישראל / יצאה לחלוקה / ממתינה לאיסוף / נמסרה
- **תאריך** — "18 באוגוסט", "20/08/2026", "מחר", "יום ראשון"
- **פעולה נדרשת** — נקודת איסוף, מכס, תשלום מיסים, ניסיון מסירה שנכשל
- **קישורים** מתוך ההודעה

> הערה: ל‑`\b` ב‑JavaScript אין משמעות ליד אותיות עבריות, ולכן הביטויים בעברית משתמשים
> ב‑lookahead ייעודי (`HE_END`) במקום גבול־מילה רגיל.

## מבנה הפרויקט

```
src/
  components/   רכיבי UI: כרטיס חבילה, ציר זמן, תפריט צד, בוטום־נאב, גיליון תחתון
  data/         רישום חנויות, חברות שילוח, ונתוני הדגמה
  lib/          תאריכים בעברית, שעות פתיחה, לוגיקת סטטוס, זיהוי הודעות
  pages/        מסך לכל מסלול
  store/        state גלובלי (React context) עם שמירה ל‑localStorage
```

**סטאק:** React 18 + TypeScript + Vite + Tailwind CSS + React Router. אין תלות בשרת.

## בדיקת המנוע מול מיילים אמיתיים

לפני שבונים שרת, כדאי לוודא שהמנוע מבין את המיילים האמיתיים שמגיעים אליך. כל מה שצריך זה
טרמינל על המחשב שלך (ב‑Mac: אפליקציית Terminal; ב‑Windows: PowerShell), ו‑Node.js מותקן
מ‑[nodejs.org](https://nodejs.org).

```bash
git clone https://github.com/SophieCoop/Parcelly.git
cd Parcelly
git checkout claude/parcelly-package-tracker-cvduxs
npm install
npm run inbox
```

בהרצה הראשונה הסקריפט **ישאל אותך** על המסך לכתובת המייל ולסיסמת האפליקציה — אין צורך ליצור
או לערוך שום קובץ. הסיסמה לא מוצגת בזמן ההקלדה, ובסוף הוא ישאל אם לשמור אותה כדי לא לשאול
שוב (נשמרת ל‑`.env`, שמוחרג מ‑git ונגיש רק למשתמש שלך).

```bash
npm run inbox -- --days 90     # לחפש אחורה יותר
npm run inbox -- --show 3      # להציג את הטקסט שהמנוע קרא
npm run inbox -- --all         # כל השולחים, לא רק חנויות ושליחים
npm run inbox -- --file a.eml  # לנתח קובץ מייל שמור, בלי להתחבר לתיבה
```

הסקריפט קורא בלבד: מנתח בזיכרון, מדפיס טבלה, ויוצא. שום דבר לא נשמר ולא נשלח לשום מקום.

**סיסמת אפליקציה של Gmail:** מפעילים אימות דו‑שלבי, נכנסים ל‑
[myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) ויוצרים סיסמה.
היא מעניקה גישה לדואר בלבד וניתן לבטל אותה בכל רגע. אפשר להדביק אותה עם הרווחים שגוגל מציגה —
הסקריפט מסיר אותם.

> שימו לב: תאריכים כמו "18 באוגוסט" נקבעים ביחס לזמן שליחת ההודעה, לא ביחס להיום — לכן
> `parseMessage(text, date)` מקבל את תאריך ההודעה כפרמטר. קליטה שתתעלם מזה תשבץ מיילים
> ישנים בשנה הנוכחית.

## מצב נוכחי

זו גרסת חזית (front-end) מלאה ועובדת. הנתונים נשמרים ב‑`localStorage` של הדפדפן,
ומגיעים מנתוני הדגמה ב‑`src/data/seed.ts`. זיהוי ה‑SMS אמיתי ורץ על הטקסט שמדביקים.

מה שידרוש שרת בהמשך:

1. **חיבור תיבות דואר** — OAuth ל‑Gmail/Outlook וסריקת אישורי הזמנה
2. **מעקב אמיתי** — חיבור ל‑API של חברות שילוח (או ספק צד־שלישי) לעדכוני סטטוס
3. **חיבור חשבונות חנויות** — משיכת הזמנות מ‑AliExpress / SHEIN / Temu / Amazon
4. **התראות פוש** — Web Push עם service worker
5. **חשבונות משתמש** — כדי שהחבילות יסונכרנו בין מכשירים

המודל ב‑`src/types.ts` ושכבת ה‑store כבר בנויים כך שהחלפת מקור הנתונים לא תדרוש שינוי במסכים.
